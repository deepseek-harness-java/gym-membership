# AI 健身房会籍管家 · 使用说明

## 一、这是什么

一个接入 DSH（deepseek-harness-java）的健身房会籍 AI 助手。前端是运营工作台，右侧 AI 助手可以直接帮你查卡种、查团课、办卡、查会籍、约团课、看运营数据——全程自然语言，无需点菜单。

## 二、启动步骤

1. **启动业务应用**（端口 18107）：
   ```bash
   SERVER_PORT=18107 java -jar p-app/target/p-app-1.0.0-SNAPSHOT.jar
   ```
2. **确认 DSH 已运行**（端口 8090）且 `gym-copilot` 插件已安装激活：
   ```bash
   curl -s http://127.0.0.1:8090/api/harness/plugins | grep gym-copilot
   ```
3. **打开工作台**：浏览器访问 http://127.0.0.1:18107

## 三、AI 能做什么（试试这些话）

| 你说 | AI 做 |
|------|-------|
| 「你们有什么会员卡种？价格和权益？」 | 调 `plan_list`，列出 4 种卡 + 教练信息 |
| 「本周有什么团课？还有名额吗？」 | 调 `class_list`，返回课表与余位 |
| 「帮我办一张季卡，姓名李小红」 | 调 `join`，**先复述要素请你确认**，确认后办理并给会员号 |
| 「查一下会员 M5001 的会籍状态」 | 调 `member_info`，返回卡种/有效期/状态 |
| 「帮王小明预约周六 10:00 杠铃塑形」 | 调 `book`，校验余位后预约，给预约号 |
| 「今天运营情况怎么样？」 | 调 `stats`，会员/收入/建议一览 |

## 四、业务规则

- **办卡确认制**：AI 办卡前必须复述卡种、价格、权益、有效期，经你确认后才真正办理。
- **编号规则**：会员号 `M5001+`，预约号 `B7001+`。
- **团课免费**：团课对有效会员免费；私教课按教练课时费（280–320 元/节）单独计费。
- **过期提醒**：会籍过期的会员查询时，AI 会提示 9 折续费优惠。
- **健康边界**：训练强度、饮食等仅做常识性提醒，不提供医疗建议。

## 五、常见问题

**Q：AI 说「（无返回内容）」或卡住不动？**
LLM upstream 偶发波动。等待约 30 秒，若仍在转圈可重启 DSH（会话缓存清空）后重试；命令行 `agent_stream.sh` 调用不受影响。

**Q：插件激活失败 / 调用了旧工具？**
先卸载再重装：`POST /api/harness/plugins/gym-copilot/uninstall`，删除 `~/.dsh/standalone/plugins/gym-copilot.jar` 残留，重新 install + activate，并重启 DSH 以清空会话缓存。

**Q：换端口怎么改？**
应用端口：`SERVER_PORT=xxx` 环境变量；插件连应用端口：环境变量 `GYM_APP_BASE_URL`（默认 `http://127.0.0.1:18107`）。
